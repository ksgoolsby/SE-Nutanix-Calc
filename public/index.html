Assumptions worth stating out loud. A vCPU is not one thing: this model bills VMware per physical core for licensing and sizes all three platforms on the same vCPU:core ratio you set above. Host count is where the two VMware architectures diverge — vSAN hosts must be added to hold capacity, so storage growth pulls licensed cores up with it, while SAN-attached host count is driven only by CPU and RAM. Elite storage is sized at replication factor 2 with an 85% usable ceiling. Array capacity is purchased raw and divided by the data reduction ratio; dual-controller HA is assumed, so no N+1 array. Downtime cost is a modeled indirect, not a billed line, and applies only to self-hosted because Elite carries an availability commitment. The 768 GB RAM uplift is $1,800/node/mo — the source deck prints "$1,1800", a typo, corrected and confirmed.
